## Rules for every task in this phase
- No game-sim change outside P8-25 (the ramp) and the LEGEND rating bonus. Quick Game at Easy/Normal/Hard must play
  exactly as before (`--autoplay` stats match the P7-T1 reference).
- Tuning constants at the top of the script they belong to (`POINTS_CITY_GAME`, `POINTS_BOSS_GAME`, the star
  ladder, `LEGEND_BONUS`, `BOSS_CAP`, `STAGE_AVG`).
- Godot 4.3, no `:=` with untyped right sides, no new `.tscn` (new screens are CanvasLayer scripts like
  `recruit.gd`), touch first (every new button is a big tap target; Escape = BACK on desktop; the Android back goes
  BACK on every new screen).
- Test runs never touch the owner's files: trips use `user://trip_test.json`, stars and cosmetics use
  `user://settings_test.cfg` (`Difficulty.unlock_path()`).
- Art: generated by `tools/art` scripts in the approved style, original, never copied from a game, team or brand;
  rerun the generator and commit its output.

## Shared contract (names fixed now so parallel tasks can call each other)

### Stars (`scripts/stars.gd`, static, `const Stars = preload("res://scripts/stars.gd")`)
- `MAX := 72`; `REWARDS := [{"at": 6, "kind": "jersey", "id": "jersey_1"}, ...]` (the ladder in
  `docs/progression-plan.md` part 4; kinds `slot`, `jersey`, `ball`, `van`, `court`, `legend`).
- `key(city_id, n) -> String` ("chicago:2", "new_york:1" for a round); `stars_for(level) -> int` (easy 1, normal 2,
  hard 3, legend 3).
- `record(key, level) -> int` (stars gained now, 0 if no better; saved); `best(key) -> int`; `total() -> int`;
  `city_total(city_id) -> int`.
- `slots() -> int`; `is_unlocked(reward_id) -> bool`; `legend_open() -> bool`; `rewards_between(a, b) -> Array`
  (unlocked when the total went from a to b, for the result screen); `next_reward() -> Dictionary`.
- Stored in section `stars` of `Difficulty.unlock_path()`. Test flags: `--startest` (prints STARTEST OK and quits),
  `--stars N` (this run acts as if the total were N; never saved).

### Cosmetics (`scripts/cosmetics.gd`, static)
- Ids: `jersey_1..3`, `ball_1..3`, `van_1..3`, `court_1..2` (display names come from the art tasks, in `ITEMS`).
- `ITEMS` (data: kind, name, files); `picked(kind) -> String` ("" = the default); `pick(kind, id) -> bool` (only
  unlocked ids; saved in section `cosmetics`); `ball_sheet() -> String`; `van_path() -> String`;
  `jersey_suffix() -> String` ("" or "_j1".."_j3"); `open_court_looks() -> Array` (court look ids for the COURT
  button). Every function falls back to the default when a file is missing.

### Files from the art tasks
- Draft recolors: `assets/players2/palettes/<sheet>_crew.png` for every city average player and every New York
  player (today only good players and bosses have one), listed in `palettes.json` like the others.
- Jerseys: `<sheet>_j<N>` (underdogs) and `<sheet>_crew_j<N>` (everyone else) palettes, listed as recolors of the
  base sheet; a missing one falls back to the plain crew palette.
- Balls: `assets/ball/ball_<N>.png` (same 4 frames of 16 x 16 as `ball.png`). Vans: `assets/map/van_<N>.png` (same
  size as `van.png`). Court looks: `assets/courts/<look>_floor.png` and `_backdrop.png`, rows in `court_looks.gd`
  with `"reward": "court_<N>"` and twist `none`.
- Sounds: `assets/sfx/star.ogg`, `stat_up.ogg`, `unlock.ogg` (synthesized, original).

### Trip (`scripts/trip.gd`) additions
- Constants: `POINTS_CITY_GAME := 1`, `POINTS_BOSS_GAME := 2` (boss game and New York rounds), `LEVELS` gets
  `"legend"`.
- `player_points(id) -> int`, `crew_points` (static var), `spend(id, stat)` uses his points first, then crew points.
- `last_outcome` gains `"points_each"` (points per starter), `"stars_before"`, `"stars_now"`, `"new_best"`,
  `"replay"`.
- Draft: `roster_limit() -> int`, `open_slots() -> int`, `draft_pool() -> Array` (player dicts), `draft(id) -> bool`,
  `is_boss(id) -> bool`, `starters_ok(ids) -> String` ("" = legal, else the reason). One boss rule (owner, P8-14b): at most one boss
  among the starters, however he joined; `set_starters()` refuses more (reason `BOSS_RULE`, "ONLY ONE BOSS CAN START").
  Also `draft_pool_by_crew()`, `draft_refusal(id)`, `can_draft(id)`, `slot_count()`, `drafted_ids()`, `beaten_crews()` (P8-14).
- Replay: `can_replay(city_id, n) -> bool`, `start_replay(city_id, n) -> bool` (sets the marker and `Flow.match`),
  `replaying() -> bool`, `stage_reached() -> int`.
- Test flag `--best-roster` (with `--city`): BLUE is the strongest legal three a trip could field there.

### Screens
- `"draft"` (`scripts/draft.gd`, args `{"back": "lineup"}`) and `"locker"` (`scripts/locker.gd`, args
  `{"back": "title"}`, only if Q3 = a). Both rows go into `flow.gd` SCREENS in P8-03 (a missing script shows the
  "not built yet" panel, so the row can come first).
- The map's replay picker lives in `trip_map.gd` (a panel, not a screen).

### Save (`trip.json` version 2; `save.gd` `VERSION := 2`)
- Roster entry: `{"id", "ratings", "pts": int, "via": "start" | "recruit" | "draft"}`. Trip: `"crew_points"`,
  `"paid": ["hometown:1", ...]`, `"replay": {}` or `{"city", "game"}`, level may be `"legend"`.
- A version 1 save: pool -> `crew_points` + catch-up (+6 per beaten city, +4 per won New York round), every beaten
  game counts as paid, `via` from the data (start / recruit), stars credited at the save's level once
  (`stars` section key `migrated_v1`). 2 or 3 boss starters (any save version) are repaired on load: the first boss
  stays, the others go to the bench for the strongest non-bosses (`Trip.boss_repair`, the lineup's note; P8-14b).
